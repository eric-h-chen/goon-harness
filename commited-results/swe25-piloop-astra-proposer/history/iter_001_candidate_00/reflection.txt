The baseline passed 14/25 tasks (0.56), with no evaluator errors. Its traces used only 5–18 model calls per task despite a 100-call allowance, so premature completion and ineffective validation were more evident than budget exhaustion.

The strongest recurring problem was interpreter selection. Failed Django, pytest, xarray, seaborn, sklearn, and SymPy traces reported missing dependencies under /opt/miniconda3/bin/python. The SymPy block-matrix trace explicitly found mpmath inside /opt/miniconda3/envs/testbed, but subsequently invoked an unavailable pytest executable. The sklearn repr trace also exposed a compiled-extension/Python-version mismatch. This replacement discovers an existing project environment and prepends its executables to every shell call, enabling meaningful testing without downloads or cross-version PYTHONPATH workarounds.

Several traces wrote placeholders, partial source, or patch syntax through write_file, then spent calls restoring files. Exact, unique replacement edits and explicit write_file validation address that failure mode. Ranged reads replace silently truncated whole-file reads; output truncation retains both the beginning and diagnostic tail.

Semantic failures also motivate a review checkpoint: the block-matrix patch passed the reported case but missed zero-matrix addition, while the homomorphism patch failed both new and existing tests after dependency errors prevented local execution. The first submit now returns the current diff and requires a focused contract, edge-case, and test review before grading. Prompts emphasize correcting the originating invariant and preserving established API behavior. Review is skipped near budget exhaustion, and the loop tracks calls, preserves provider metadata, catches tool errors, and stops immediately after terminal submission.

Validation: JavaScript syntax checking passed, and a mock API verified exact editing, first-submission interception, and a single terminal submission. No benchmark evaluation was run; the pass-rate improvement remains unmeasured.
